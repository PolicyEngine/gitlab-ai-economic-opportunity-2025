# Budget

Budget documentation for the GitLab Foundation AI for Economic Opportunity Fund application.

## Grant Amount

$250,000 seed funding

## Budget Structure

Create budget files that address:

### Personnel Costs
- Salaries and wages
- Fringe benefits
- Consultant fees

### Project Costs
- OpenAI API usage (supplementing provided credits)
- Software licenses and tools
- Data acquisition and processing
- Hosting and infrastructure
- Equipment (if applicable)

### Operations
- Administrative overhead
- Project management
- Evaluation and measurement
- Communications and dissemination

### Other Costs
- Travel (e.g., to Demo Day at OpenAI HQ)
- Training and professional development
- Partnerships and subcontracts
- Contingency

## Budget Narrative

For each line item, provide:
1. **Description**: What is this expense for?
2. **Justification**: Why is it necessary?
3. **Calculation**: How was the amount determined?
4. **Alignment**: How does it support project objectives?

## Example Budget Format

```markdown
## Personnel: $150,000

### Lead Engineer (0.5 FTE) - $85,000
- 50% time over 6 months
- Responsible for AI model development and OpenAI API integration
- Calculation: $170,000 annual salary × 0.5 FTE × 0.5 years

### Data Scientist (0.3 FTE) - $45,000
- 30% time over 6 months
- Responsible for impact evaluation and data analysis
- Calculation: $150,000 annual salary × 0.3 FTE × 0.5 years

### Project Manager (0.2 FTE) - $20,000
- 20% time over 6 months
- Responsible for coordination, reporting, and partnership management
- Calculation: $100,000 annual salary × 0.2 FTE × 0.5 years

[Continue for all budget categories...]
```

## Total Budget

Ensure total equals $250,000 and allocations align with project needs and funder expectations.

## Notes

- OpenAI API credits are provided as part of the grant
- Consider what technical support from OpenAI engineers covers vs. what you need to budget for
- Demo Day travel may be covered separately - confirm with program officer
- Indirect costs/overhead - check if there are any restrictions
