# Concept Note Application

This directory contains the concept note application (first stage) for the GitLab Foundation AI for Economic Opportunity Fund.

## Timeline

- **Deadline**: October 31, 2025 (5:00 PM PT)
- **Notification**: November 14, 2025

## Structure

- `questions/`: Question requirements and structure files
- `responses/`: Individual response files (one per question)
- `ASSEMBLED_CONCEPT_NOTE.md`: Complete assembled concept note (generated)

## Workflow

1. **Edit response files** in `responses/*.md`
2. **Run assembler** (if available): `python3 assemble_concept_note.py`
3. **Review output** for completeness and accuracy
4. **Commit changes** to both source and generated files

## Application Components

Based on typical concept note requirements, expect questions about:

- **Project Summary**: Brief overview of the AI-powered solution
- **Problem Statement**: What economic mobility challenge are you addressing?
- **AI Solution**: How does AI specifically help solve this problem?
- **Impact**: What outcomes will the project achieve?
- **Target Population**: Who will benefit?
- **Feasibility**: Why is this realistic and achievable?
- **Team**: Who will lead and execute the work?
- **Budget Overview**: High-level budget narrative
- **Timeline**: Key milestones

## Tips for Strong Concept Notes

1. **Be Specific**: Avoid vague language about "using AI to help people"
2. **Show Transformation**: Demonstrate how this meaningfully changes economic opportunity
3. **Connect AI to Outcomes**: Clear causal chain from AI capability to economic impact
4. **Demonstrate Feasibility**: Show you can actually deliver this
5. **Highlight Team Strengths**: Expertise in both AI/tech and economic mobility
6. **Address Equity**: How will you serve underserved communities?
7. **Be Realistic**: Don't overpromise; show clear path to success
